☁️ 云同步（GitHub Gist）

使用 GitHub Gist 实现跨设备同步。电脑和手机填入相同的 Token 和 Gist ID 即可共享数据。

首次设置（只需做一次）：
① 打开 github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
② 点 Generate new token → 权限勾选 Gist → 生成后复制 Token（github_pat_...）
③ 打开 gist.github.com → 新建一个 Gist（文件名填 workbench.json，内容任意）→ 创建后复制地址栏里的 Gist ID

💡 自动同步：每次操作数据后 1.5 秒自动上传（建议只在主力设备开）。打开时自动下载：每次打开自动从云端拉取最新数据（适合手机/副设备）。
